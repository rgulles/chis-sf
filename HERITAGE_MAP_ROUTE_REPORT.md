## Main Map Directions

DirectionsModal and the separate RouteMap were removed. Site Detail, directory, main Map cards and Katulung share App.openDirections and navigate to #/map?destination=ID. Only the destination ID enters the URL. Refresh/back/forward parse that state; closing removes route mode and retains the selected site for browsing.

MapView lazily loads DirectionsPanel inside the existing Map page. Desktop uses a 320px side panel and a dominant map; mobile uses a lower panel with a 400px map, independent scrolling and fixed estimate rows within the panel. It does not lock page scrolling or open a modal. The guide closes when its Directions action is selected.

GPS runs only after USE MY CURRENT LOCATION, with high accuracy, a 12-second timeout and 30-second maximum age. Permission denial, unavailable position, timeout, insecure context and unsupported browser have explicit messages. Coordinates and the visitor-route cache stay in component memory. Closing/unmounting clears state, aborts OSRM and ignores late callbacks; changed destination ID or coordinates remounts the panel. No location is sent to CHIS, persisted, added to analytics or placed in a URL. The privacy note states that CHIS does not save the location and that the routing service receives coordinates.

Directions reuses the itinerary OSRM abstraction and its distance/duration/step formatters. VITE_OSRM_BASE_URL defaults to https://router.project-osrm.org. Requests use /route/v1/driving/startLon,startLat;destLon,destLat?overview=full&geometries=geojson&steps=true, after successful GPS only. A 15-second timeout and public-demo pacing remain. Requests with an abort signal bypass the global itinerary cache; visitor routes cache only in the panel lifetime.

The main map renders a current-location marker, highlighted destination marker and actual returned road geometry. City boundary context remains, while navigation bounds relax to include visitors outside the city. Route bounds include start and destination. Failure keeps markers, shows Road directions are temporarily unavailable, and omits distance/time/polyline. No straight line or fake transit content was added. Estimates use OSRM values, rendered as 650 m / 4.8 km and 12 min / 1 hr 15 min, labelled Estimated driving time. Guidance uses only returned names/maneuvers/distances with neutral fallback instructions; it is a preview without live traffic or navigation claims.
